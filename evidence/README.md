# Georgie Peptide Bible — Evidence Vault

This folder is the source-of-truth index for the client information hub. Files are grouped here so each workstream can point back to the evidence, research, financial models, supplier qualification, logistics controls, packaging direction, and creative studies that support it.

## Workstream mapping

| Hub room | Primary evidence |
| --- | --- |
| Business plan | demand assessment, audience matrix, competitor landscape |
| Marketing plan | lean budget, 90-day workbook, copywriting templates, TikTok / Instagram strategy |
| Procurement & imports | supplier qualification tracker, supplier due diligence evidence pack, procurement and stock-management guide |
| Transport & logistics | cold-chain standard, operations control workbook, transport and importation guide |
| Product catalogue | product catalogue draft, global trend reports, category pricing landscape |
| Product research | scientific trend reports, research provenance, South Africa source log |
| Brand studio | five identity territories, UI / UX specification, creative opportunity audit |
| Website ideas | UI / UX specification, CRM / analytics / WhatsApp setup guide |
| Financial model | six-month forecast, 90-day marketing budget, operations workbook |
| Data vault | this index, source files, and the uploaded supplier evidence archive |

## Operating rule

The UI should present conclusions and next decisions, while the vault preserves the underlying documents and evidence trails. Claims should stay bounded to the scope supported by the source material.
